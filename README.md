# 火线运输船（FPS Demo）

类战地风格的第一人称射击网页游戏，地图参考穿越火线经典地图「运输船」。
纯 Three.js + 原生 Web API 实现，**零外部资源**（贴图用 Canvas 程序化生成、音效用 Web Audio 合成），无需构建。

## 运行

```bash
node server.js        # 然后浏览器打开 http://localhost:8080
```

或双击 `启动游戏.bat`（自动开浏览器）。

## 玩法

- **模式**：团队死斗 5v5 / 10v10 可选（你 + N 名 AI 队友 vs N 名 AI 敌人），两种模式：击杀赛（率先 50 杀获胜）/ 定时赛（可选 10 / 20 / 30 分钟，时间耗尽时比分领先获胜）
- **反馈**：仿穿越火线的连杀徽章（击杀 / 双杀 / 三连杀 / 四连杀 / 超神连杀）；阵亡时右下角弹出本条命的"伤害输出"面板
- **武器**：AK-47 步枪（全自动）/ M870 霰弹枪（9 弹丸）/ AWM 狙击（8 倍镜）/ M9 手枪
- **近战**：匕首 / 斧头 / 铁铲 / 手里剑（投掷型，按 5 连按轮换）
- **投掷物**：手雷 / 烟雾弹（阻断 AI 视线）/ 闪光弹（致盲正对爆点的敌人，按 6 轮换）
- **机制**：爆头 2 倍伤害、距离衰减、后座力/扩散、冲刺/蹲伏/跳跃、脱战 5 秒回血、出生 2 秒无敌保护
- **AI**：路点寻路 + 视线/听觉感知 + 反应时间与瞄准误差（三档难度）
- **地图**：对称甲板三路结构 —— 中路对狙高台（两侧坡道）、交错隔断墙、侧翼走廊、基地掩体墙

## 操作

| 按键 | 功能 |
|---|---|
| W A S D / Shift / C / 空格 | 移动 / 冲刺 / 蹲伏 / 跳跃 |
| 鼠标左键 / 右键 | 射击 / 机瞄·开镜 |
| R / 1 2 3 / 滚轮 | 换弹 / 切换武器 |
| G / 鼠标中键 | 手雷 |
| Tab / Esc | 计分板 / 暂停 |
