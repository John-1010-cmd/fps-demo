## 1. 目标、边界与依据

目标是参考图可辨认且经近景检视的展示级资产，不是“跑通脚本就完成”。militia 与 swat 的轮廓、比例、眼部、装具层次、身份标记、持枪关系与纹理边界必须对应原图，隐藏区域以推断标注。showcase 是完整度标杆，不是另一个人物的造型模板。

依据优先级：用户当前要求 → 本轮确认的路线/质量契约 → 版本化 spec → 已锁定本机工具源码及参考契约。工具 schema 或门禁与规划不符时修正规划/适配器，不伪造输出、绕过停止条件或修改外部 skill 来迁就验收。

**纳入**：人物 ×2、随附轻量武器 ×2、独立展示台、投影执行器、真实 rig/运行时验证；后续独立武器 ×2。

**排除**：游戏高模化、游戏战斗/HUD/音频调整、外部角色下载或神经重建替代程序化工厂、默认 death/布娃娃/手指 IK/高级 HDRI。旧 `reviews/`、旧 `HANDOFF.md` 不作为依据；按用户要求删除后，新 `HANDOFF.md` 只记录可复核状态/入口，不另立验收契约。

游戏冻结范围包括 `index.html`、`css/style.css`、`js/game.js`、`js/main.js`、`js/config.js`、`js/audio.js`、`js/hud.js`、`js/soldiers.js`、`js/weapons.js`、`js/map.js`、`js/effects.js`、`js/utils.js`、`js/soldier_models/`、`js/model-review.js` 与 `model-review.html`，以及游戏导入链中其他已有模块；`server.js` 与 `js/vendor/three.module.js` 也保留原基线。英雄专用样式另设 `css/hero-demo.css`；新评审台不借用游戏评审页。确需例外先说明原因和回归范围，不能顺手扩展。

2026-10-01用户已说明完成 stash；本次核验只有规划文档改动仍在，游戏/旧 demo 回到基准提交，旧 ignored 缓存仍存在。二次复审未执行 stash/pop/reset/commit，也未恢复旧实现；只按用户授权删除旧交接/评审文档并重写 HANDOFF。用户检查规划、要求开始实施后，再按以下清单完成正式基线：

6. 冻结游戏范围的文件哈希与低模 API 基线；逐里程碑核对零变更。新实现不得从旧 stash 未经审查地复制代码、PASS 表或指标。

05 篇从 M0 就介入。七 pass 的中文阶段与机器 ID 按 02 篇对应；静态 pass 中的 referencePose/关节预检使用隔离的临时 pose/skin 候选，不能提前标记正式 rig 完成。interaction 只验证静态分件/socket/UI 接口，完整 clip UI 在正式 rig 九步后验收。

正式顺序是七 pass → base FINAL（含 emission-target/plugin-gates 的明确处置）→ domain rig 九步 → 完整 demo。02 篇规定固定 state 路径与 FINAL 适配，M0 必须证明 next 可走到 rig 阶段；没有 producer 的终态不能靠 exit0 或越序 mark 解锁。R0～R6 是概念阶段，不是九个 step 的别名。

## 6. 风险与停止规则

| 风险 | 处理方式 |
|---|---|
| 工具描述符/默认数值被当成完成 | M0 样例先证明读写和执行器；每项证据含来源、版本、覆盖与输出哈希 |
| 只看剪影，头巾/眼部/装具缺细节 | matched-view + 内部区域 + 关键特写；任何 critical feature 错误阻断 |
| 拿持枪原画直接投影 T-pose | 明确参考姿态/绑定姿态分离；仅在匹配姿态投影，UV 跟随回绑定姿态 |
| 背部/腋下无参考 | per-region 置信度、调色板补全，不声称百分百还原或把手/枪背景烘进躯干 |
| 达到 3/pass 或 6 total | 停止自动修正；保存最佳候选及问题，不以平台期或上限作为验收通过 |
| 更高精武器热替换超人物预算 | 显式 `character` 轻量变体；不得把 15k/18k 展示网格直接塞到 6k 挂载预算 |
| 预算导致身份细节消失 | 先合批/材质分组/不可见面优化；仍不足时提交具体预算变更请求，不悄悄砍特征 |
| 本机版本/服务漂移 | 重新能力核验与捕获，不修外部 skill、不重启用户服务掩盖问题 |

回退限本轮明确修改的资产及检查点；禁止整仓 checkout/reset、覆盖用户改动或自动删除 ignored 目录。降级预览不能变成英雄版 PASS。
